# Как получены прогнозы

Решение оценивает каждую `cookie_id` по событиям в её суточном окне. Чем выше
`score`, тем вероятнее, что кука относится к трафику известных сервисов
автоматизированного сбора данных. Оценки лежат в диапазоне от 0 до 1 и служат
для ранжирования; калибровку вероятностей мы не проводили.

## Признаки и модель

Для каждой куки мы оставляем события с
`window_start_ts <= event_ts < window_end_ts` и удаляем полностью совпадающие
строки. Считаем частоты действий, интервалы между ними, последовательности,
активность по времени, просмотры объявлений, поисковые действия, платформу и
User-Agent. Отдельно считаем признаки по объявлениям, которые уже встречались
у других кук. В эту историю попадают только куки, чьи окна закончились до
начала текущего окна.

Работают две модели `HistGradientBoostingClassifier`. Первая использует 331
признак, вторая — 251. Сокращённый набор выбран на ранней размеченной части
обучения и зафиксирован до проверки. У моделей одинаковые параметры:
440 итераций, `learning_rate=0.04`, не более 15 листьев, минимум 25 объектов
в листе и L2-регуляризация 3. Их прогнозы усредняются поровну.

После усреднения мы учитываем общие просмотренные объявления. Для объявления
берём средний базовый прогноз прошлых кук, уменьшая вес популярных объявлений.
Если у текущей куки есть хотя бы два совпадения с прошлой историей, итоговая
оценка равна `0.8 × прогноз моделей + 0.2 × оценка соседей`. В остальных
случаях остаётся прогноз моделей. Скорректированные оценки в историю не
возвращаются.

## Проверка результата

Качество измеряли по кукам: максимальная precision при recall не ниже 70%.
Обучение каждого фолда заканчивается до начала его проверочного периода.
Для исторического шага на размеченных куках использовали прогнозы вне
обучающего фолда, чтобы модель не опиралась на собственные прогнозы по тем
же обучающим строкам.

| Временная проверка | Усреднение моделей | С учётом общих объявлений |
|---|---:|---:|
| Основные фолды, 10–17 апреля | 0,822660 | 0,830049 |
| Поздний срез, 17–20 апреля | 0,862595 | 0,875969 |

На основных фолдах прирост целевой метрики составляет 0,007389. Поздний срез
использовался при выборе решения, поэтому независимым тестом не считается.
На отдельных основных фолдах результат равен 0,812950, 0,848485 и 0,842424:
планка 0,85 на каждом фолде не достигнута. PR-AUC и ROC-AUC после поправки
снизились; улучшение относится только к целевой метрике. Результат на скрытой
выборке пока неизвестен.

## Воспроизведение

Проверенная версия Python — 3.12.14. Зависимости закреплены в
`requirements.txt`. Ячейки `solution.ipynb` выполняются по порядку и создают
`result/submission.csv` с колонками `cookie_id,score`. Данные входят в архив,
а выбранные параметры и списки признаков записаны в ноутбуке. Готовый файл
сдачи содержит 4 909 строк — по одной на каждую куку из тестовой выборки.
